# GMS 守护

给国行 ColorOS 用的 LSPosed 模块：

- 防止系统在重启或网络变化后断掉 Google Play 服务、Play 商店和 Google 服务框架的网络。
- 关闭手机管家、电话框架、安全卫士和 Google Play 服务里的 AI 通话反诈与诈骗来电检测。
- 关闭国家反诈中心拦截服务、疑似诈骗号码拦截，以及系统对反诈中心号码来电的专门拦截处理。
- 关闭安全中心通过辅助功能风险接口触发的诈骗防护动作。
- 关闭 Android 通话期间的增强确认和未知来电安装限制。
- 通过系统框架向普通应用隐藏无障碍服务名单、开发者选项和 ADB 设置状态。

普通骚扰电话和短信拦截、黑白名单及病毒扫描不在处理范围内。

## 使用方法

1. 下载 APK 并安装。
2. 在 LSPosed 中启用模块，勾选模块推荐的作用域。
3. 重启手机。

## 适配情况

目前按下面两套环境开发和测试：

- OnePlus 15 / PLK110
- Android 16 / ColorOS 16.0.9.400 / 手机管家 17.1.6
- Android 17 / ColorOS 17.0.0.105 / 手机管家 17.6.8

本次新增的状态隐藏已在 Android 17 设备上验证，Android 16 尚未实机验证这部分功能。

系统或手机管家更新后，类名和组件名可能变化。如果功能失效，请带上机型、系统版本和 LSPosed 日志提 Issue。

## 大致原理

GMS 联网部分由 system_server 和电池管理进程处理。Google Play 服务的反诈检测服务也由 system_server 和 Telecom 拦截。Android 17 使用新的 `OAppNetControlManager` 接口，模块会同时兼容新旧两套接口。

模块按组件和功能入口处理反诈，不会停用整个电话、Google Play 服务、安装器、权限控制器、手机管家、安全卫士或安全中心。Telecom 不再绑定 Google 银行诈骗来电检测和 Android 增强确认跟踪服务；Android 相关功能标志只在读取时返回关闭，不改写 DeviceConfig。黑名单应用只关闭国家反诈中心服务和疑似诈骗号码规则，普通骚扰拦截仍由系统处理。安全卫士的诈骗行为序列检测及安全中心对应的辅助功能风险动作也会被拦截。

无障碍状态隐藏随推荐的系统作用域生效。模块根据调用方 UID 自动判断：提供无障碍服务的应用保留真实服务名单和无障碍设置；其他普通应用得到空名单和关闭的无障碍设置。应用声明了受 `BIND_ACCESSIBILITY_SERVICE` 保护的服务，或已有服务被启用，都会被识别为服务提供方。开发者选项和无线 ADB 设置对普通应用返回关闭。系统应用、ADB shell 和 Google 核心组件保留真实状态。
状态隐藏覆盖 `Settings` 读取、设置提供器的查询和列表接口，以及无障碍服务列表。`AccessibilityManager.isEnabled()` 保留真实值，窗口框架需要这个状态来发送事件、建立连接。模块不关闭实际无障碍服务、开发者选项或 USB 调试，也不修改系统属性、应用安装列表和完整性检测结果。

这些处理都在运行时生效，不写入系统组件启用状态。停用或卸载模块并重启后，相关功能恢复系统原本行为。模块没有定时轮询。

1.1.27 用于清理旧版本留下的组件禁用状态。确认升级并重启后可安装 1.1.28 或更新版本；后续版本不再包含这段迁移清理代码。
